# Time Tracker

Простое веб-приложение для учёта рабочего времени сотрудников.

## Возможности

- Единый блок «Сотрудники и таймеры»: у каждого сотрудника видно текущую задачу и идущее время таймера.
- Старт таймера через окно с описанием задачи: кнопка «Старт» неактивна, пока описание пустое.
- Пагинация списка сотрудников по 10/20/50 на странице.
- Режим «Редактировать»: удаление сотрудников (идущий таймер при этом останавливается) и перестановка перетаскиванием или стрелками.
- Запуск и остановка таймера с описанием задачи; у одного сотрудника может быть только один активный таймер (гарантируется уникальным индексом в БД).
- Редактирование записей времени.
- Отчёт за период: записи, пересекающие границы периода, обрезаются по ним.
- Данные хранятся в SQLite и переживают перезапуск.

Все ошибки API возвращаются одной строкой на русском в поле `detail`.

## Стек

Python 3.9+, FastAPI, SQLite, статический UI на HTML/CSS/JS.

## Запуск

```bash
./run.sh
```

Скрипт создаст `.venv` (если нет), поставит/обновит зависимости и поднимет сервер на http://127.0.0.1:8765.
При первом запуске база `time_tracker.db` заполняется демо-сотрудниками.

## API

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/employees` | список сотрудников |
| POST | `/api/employees` | добавить сотрудника |
| GET | `/api/employees/board?page=1&per_page=10` | страница сотрудников с текущими таймерами (10/20/50) |
| POST | `/api/employees/{id}/move` | переставить сотрудника (`{"to_index": 0}`) |
| DELETE | `/api/employees/{id}` | удалить сотрудника (идущий таймер останавливается) |
| GET | `/api/timers/active` | активные таймеры |
| POST | `/api/timers/start` | запустить таймер |
| POST | `/api/timers/stop` | остановить таймер |
| GET | `/api/entries/{id}` | запись времени |
| PATCH | `/api/entries/{id}` | изменить запись |
| GET | `/api/reports/period` | отчёт за период |

Интерактивная документация: http://127.0.0.1:8765/docs
